# 🧮 Java Calculator Automation Testing Project

Проект автоматизированного тестирования базовых функций калькулятора на языке Java с использованием фреймворка JUnit 5. Создан в учебных целях для демонстрации навыков написания тестов и работы с системой контроля версий Git.

## 🚀 Стек технологий
* **Language:** Java 17+
* **Testing Framework:** JUnit 5 (Jupiter)
* **Build Tool:** Gradle / Maven (выберите ваш вариант)
* **VCS:** Git & GitHub

## 📋 Покрытый функционал (Что протестировано)
* [x] Сложение и вычитание чисел
* [x] Умножение
* [x] Деление чисел
* [x] **Обработка исключений:** Написан тест на валидацию деления на ноль с проверкой генерации ошибки `ArithmeticException`.

## 🛠️ Как запустить тесты локально

1. Склонируйте репозиторий к себе на компьютер:
   ```bash
   git clone git@github.com:QAVasiliyArbuzov/test.git
   ```
2. Откройте проект в **IntelliJ IDEA**.
3. Запустите тесты с помощью встроенного сборщика Gradle:
    * Нажмите кнопку `▷` (Run) слева от тестового класса `Calculator_tests`.
    * Или выполните команду в терминале: `./gradlew test`
